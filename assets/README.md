`qrcode.min.js` is vendored from [davidshimjs/qrcodejs](https://github.com/davidshimjs/qrcodejs/tree/04f46c6a0708418cb7b96fc563eacae0fbf77674), under the MIT license in `qrcode-LICENSE`. It generates join QR codes locally in the browser.

`twitch-voting.js` provides host connection controls and the separate Twitch tally. `twitch-config.js` optionally prefills the public service origin; all secrets belong in the server environment. See [Twitch setup](../twitch-service/README.md).
